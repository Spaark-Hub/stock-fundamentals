The first time user needs to signup for the platform. The Signup uses NoSQL MongoDB Database in which the password is encrypted using bcrypt-sha encryption.

### Installation

First, clone the repository using 'git clone'. Then run

```
cd stock-fundamentals
```

This code is tested on Python 3.11, but there should be compatibility for some adjacent python versions (although it is not thoroughly tested)

You can first create a virtual environment, and then install all the required packages by running the following command:

```
pip install -r requirements.txt
```

### Usage

To run the web application, run the following command:

```
python manage.py runserver
```
